＃タスク管理アプリ
初めての自作アプリです。tabで機能を分けるなどの大まかな設計は自分で考えました。コーディングにAI使用

＃アプリの概要
日々のタスクを管理できるタスク管理アプリです。やるべきことを忘れないようにする用の機能が多め

＃できること
・todoリスト
・月間カレンダー
・週間カレンダー
・ポモドーロタイマー
・ルーティーン管理

＃作った理由
自分が使いたい機能だけを詰め込んだタスク管理アプリが欲しかったから
夏休みで暇だったから

＃工夫したこと、学んだこと
機能ごとにタブで分けた。
設計をメインで考え、コーディングなどの作業はAIにやらせることで開発時間を短くした。
アプリに加えた変更の保存方法を学んだ。
